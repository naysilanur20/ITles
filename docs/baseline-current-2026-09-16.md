# Исходное состояние текущего продолжения

Дата: 2026-09-16. Исходный Git: `4a236b2a158beb09d21387eb9dc7864a3c2d8230`.
`docs/baseline-2026-09-16.md` описывает более раннюю версию, не этот исходный код.

## Работает на проверенном стенде

- Репозиторный setup, сборка и генерация документов.
- 139 Python-тестов и 52 frontend-теста; синтетическая нагрузка: 10 000 событий
  и 10 000 повторов, раздельный итог `1234.560000` м³.
- Веб-регистрация, индивидуальная авторизация, административный API, исходный
  мастер настройки уже реализованы. Переписывать backend для оформления не требуется.
- Чистый Chrome, `http://127.0.0.1:3000/`: POST демо и последующее чтение парка
  успешны. Полный FastAPI, локальная SQLite, `ITLES_DEMO_ENABLED=1`,
  локальный HTTP-режим `ITLES_COOKIE_SECURE=0`. Это не испытание внешнего HTTPS.

## Воспроизведённые дефекты и пробелы

1. Регистрация могла занять служебный код демо до первого открытия. Последующее
   создание сценария завершалось исключением.
2. Приём события с предсказуемым UUID учебного сценария мог заблокировать seed
   из-за глобального первичного ключа. Существующий конфликт давал HTTP 500.
3. Проверка поступления стирала несохранённую форму источника; после неуспешного
   обновления сохранялась возможность действий по прежним сведениям.
4. Замена кода сотрудника сбрасывала пароль и сеансы без отдельного подтверждения.
   Отзыв переходного legacy-доступа был скрыт в UI, хотя поддерживался API.
5. В реестре повторялись машины из списка проблем и несколько пояснений времени;
   отсутствовал фильтр проблемных/непоступавших данных.
6. Диагностика ошибок не содержала времени, endpoint и сборки интерфейса.
   В поставляемые архивы не входил HANDOFF; воспроизводимой браузерной регрессии не было.
7. Сквозная проверка HTTP ingest обнаружила старый снимок показаний при переходе
   из настройки источника к уже выбранной машине. До ручного обновления UI показывал
   отсутствие вместо только что полученного нуля.

Дефекты подтверждены новыми регрессиями, а не взяты из старых отчётов.

## Не предоставлено / не подтверждено

Точный внешний адрес, браузер и время пользовательского отказа демо неизвестны.
Найденные конфликты не объявляются причиной этого отказа. HTML 405 от старого nginx —
исторический эпизод. Для внешней диагностики нужен URL и сведения из раскрытия ошибки,
не пароль, токен или содержимое cookies.

Нет реального файла OEM, документации конкретного бортового компьютера и прав
доступа к технике. Нет универсального OEM/CAN/StanForD-адаптера, полевой и
метрологической проверки, интеграции с конфигурацией 1С заказчика.
